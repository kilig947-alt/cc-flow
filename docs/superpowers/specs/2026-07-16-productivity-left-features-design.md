# CC FLOW 原生生产力左侧功能设计

## 目标

参考 BooBar 的工作流能力，为 CC FLOW 增加一组原生、可独立启用的左侧功能。每项功能都沿用现有 `LeftFeatureStore` 的排序、紧凑态选择、展开态选择、尺寸持久化、固定和全局快捷键能力，同时保持本地优先、最小权限和低后台能耗。

新增八项内置功能：系统监控、日历、GitHub、文件卡片、自然搜索、下载监控、浏览器资源和邮件助手。现有用量、音乐、中转站、热点新闻、Mineradio 及 Codex/Claude 会话能力保持独立。

## 产品原则

- 八项功能分别注册为稳定的 `LeftFeatureKind`，可以独立启用、禁用、排序和选择。
- 新功能对新用户和升级用户均默认关闭；只有用户主动启用或进入配置流程时才请求权限。
- 文件整理只生成 File Card 和建议。移动、重命名或归档必须展示来源、目标和变化，并由用户确认。
- 浏览器资源功能不自动修改书签；邮件助手不修改、删除或标记邮件；日历首版只读。
- AI 是可选增强层。AI 不可用时，元数据、OCR、本地规则和基础搜索仍然工作。
- 所有后台采样、监听和轮询接入 `EnergyGovernor`；禁用功能后停止对应服务。

## 功能设计

### 系统监控

- 紧凑态显示当前网络速率、内存压力或磁盘告警中的最高优先级摘要。
- 展开态显示今日应用使用时长、网络上下行及短时趋势、磁盘容量、内存压力和设备摘要。
- 应用使用时间从功能启用后由 CC FLOW 根据前台应用切换累计；锁屏、睡眠和用户空闲时间不计入，不读取系统历史屏幕使用时间。

### 日历

- 通过 EventKit 读取用户授权的系统日历和提醒事项。
- 紧凑态显示下一个事件或当天剩余待办数量；展开态使用月历与当日日程双栏布局。
- 首版只读，不创建、编辑或删除事件与提醒事项。

### GitHub

- 优先复用本机 `gh` CLI 登录；不可用时使用存入 Keychain 的 Personal Access Token。
- 展开态展示用户资料、贡献热力图、仓库摘要和近期活动；紧凑态展示贡献或近期活动摘要。
- 提供刷新、认证状态和恢复入口，不在本地明文保存令牌。

### 文件卡片

- 默认支持下载、桌面和系统截图目录，并允许用户通过安全作用域书签添加任意自定义目录。
- 文件稳定后提取名称、路径、类型、大小、创建时间、图片 OCR、标签、摘要和整理建议。
- 每项建议进入确认界面；执行前重新验证源文件身份和目标冲突。成功操作写入审计记录，并在可安全恢复时提供撤销。
- 支持忽略规则、暂停目录监控和移除授权。移除授权后立即停止访问对应目录。

### 自然搜索

- 使用本地 SQLite FTS 搜索文件名、路径、File Card、OCR 和标签，不索引文档正文，不引入向量数据库。
- 搜索结果显示匹配原因，并支持在 Finder 中显示原文件。
- AI Provider 可把自然语言查询转换为结构化检索条件，但最终查询与排序在本地执行。

### 下载监控

- 接收 Chrome、Edge 和 Safari 扩展发送的下载开始、进度、完成、失败和取消事件。
- 紧凑态优先显示活动下载；展开态按活动、最近完成和失败分组，并提供显示文件和重试指引。
- Chrome 与 Edge 共用 Manifest V3 扩展核心；Safari 使用 Safari Web Extension 容器复用同一事件模型。

### 浏览器资源

- 接收保存当前页、检测到的可下载资源、网页变化和书签整理请求，生成本地资源卡片与分类建议。
- 不自动修改浏览器书签；建议必须由用户确认，首版确认结果只写入 CC FLOW 的本地资源库。
- 浏览器客户端使用一次性配对令牌、客户端类型和协议版本完成本地握手。

### 邮件助手

- 用户启用并授予 Automation 权限后，通过 macOS 邮件 App 本地适配器读取必要字段。
- 提取验证码和用户规则命中的重要邮件；紧凑态显示最新验证码或重要提醒。
- 默认不持久化完整正文，只保存发件人、主题、时间、最小摘要、验证码及原邮件定位信息。
- 不修改、删除或标记邮件；轮询频率由 `EnergyGovernor` 控制。

## 共享架构

### 功能注册与生命周期

- 扩展 `LeftFeatureKind` 和稳定内置 ID，并以幂等迁移把八项功能追加到已有配置，默认 `isEnabled = false`。
- 每项功能提供紧凑态和展开态原生 SwiftUI 视图，并响应启用、禁用、激活、收起、睡眠和唤醒生命周期。
- 服务状态统一为 `disabled`、`permissionRequired`、`loading`、`ready`、`degraded` 和 `failed`，页面必须给出可执行的恢复操作。

### 事件与本地存储

- 新建 `ProductivityEventStore`，接收文件、下载、网页、邮件和建议事件，并向各功能提供独立投影视图。
- 使用 SQLite 保存 File Card、OCR、标签、授权引用、浏览器资源、邮件最小摘要、操作建议和审计记录；FTS 只覆盖约定的搜索字段。
- 长耗时 OCR、索引、CLI 调用和网络请求在后台执行，主线程只发布不可变快照。

### AI Provider

- 新建共享 `AIProviderService`，支持 Codex CLI、Claude Code CLI、OpenAI-compatible API 和 Local Rules 四种选项；每个 AI 功能可独立选择 Provider。
- CLI Provider 使用结构化 JSON 输入输出，并支持超时、取消、登录检测和输出校验。
- OpenAI-compatible Provider 配置 base URL、模型和 Keychain 密钥；日志不得包含密钥或完整敏感内容。
- 每次请求只发送完成当前任务所需的最小字段。Provider 失败时保留本地结果，并把功能状态标记为 `degraded`。

### 系统适配器

- 系统监控使用 `NSWorkspace` 和受支持的系统统计接口；日历使用 EventKit；图片 OCR 使用 Vision。
- GitHub 数据通过 `gh api` 或 GitHub REST API 获取。
- 浏览器扩展通过本地受限 bridge 发送版本化事件，不接受任意命令执行或任意文件路径读取。
- Mail 适配器仅在功能启用且权限有效时运行。

## 交互与视觉系统

- 使用原生 SwiftUI 和现有 flow Island材质，采用深色、高密度、内容优先的仪表盘风格，不复制 BooBar 的大面积荧光描边。
- 使用 8pt 间距体系、12pt 卡片圆角、SF Symbols 和系统字体；数字与时间序列使用等宽数字。
- 语义色区分正常、警告、失败和进行中状态，并同时提供图标或文字，禁止只依赖颜色。
- 实时数据以可读数字为主、短时趋势图为辅；网络趋势使用可暂停的短窗口折线/面积图，应用时长使用带数值标签的排序条形图，GitHub 贡献热力图提供文字摘要。
- 图标按钮保留至少 44×44pt 命中区域，提供 hover、pressed、disabled、focus 状态及明确的无障碍标签。
- 加载超过 300ms 时显示骨架或进度；空状态说明原因和下一步；错误同时说明原因与恢复操作。
- 微交互控制在 150–300ms，支持系统“降低动态效果”，不使用持续装饰动画。
- 支持键盘导航、VoiceOver、中英文和动态文字尺寸；较大文字下允许内容换行或滚动，不静默截断关键数据。

## 权限与隐私

- 权限按功能渐进请求：目录使用安全作用域书签，日历使用 EventKit 授权，邮件使用 Automation，浏览器使用显式扩展配对。
- 设置页集中显示每项权限、数据来源、最后更新时间、暂停状态和撤销授权入口。
- GitHub PAT 与 OpenAI-compatible API 密钥只存 Keychain。
- 数据库和审计日志位于 CC FLOW 应用支持目录；提供清除单项功能数据和清除全部生产力数据的操作。
- 禁用功能不会自动删除历史数据，但必须停止后台活动；用户可在禁用时选择同时清除数据。

## 失败与边界处理

- CLI 未安装或未登录、API 超时、GitHub 限流、扩展断连、Mail/EventKit 权限拒绝均显示功能内恢复入口，不影响其他功能。
- 文件处理期间源文件消失、发生变化或目标冲突时取消执行并要求重新确认，不覆盖已有文件。
- OCR 不支持或失败时仍创建仅含元数据的 File Card。
- 搜索索引损坏时允许从 File Card 数据重建；重建期间显示进度并保留基础文件名搜索。
- 浏览器协议版本不兼容时拒绝事件并提示升级对应扩展。

## 分阶段交付

1. 共享基础设施、功能类型迁移、权限中心、Keychain、SQLite/FTS、AI Provider、系统监控和日历。
2. 目录监控、Vision OCR、File Card、建议确认、操作审计、撤销和自然搜索。
3. GitHub、Chrome/Edge/Safari 扩展、下载监控和浏览器资源。
4. Mail 适配器、邮件助手、统一设置、能耗优化、无障碍、本地化和完整回归。

每个阶段都必须保持应用可构建，并且已交付功能可独立启用和禁用。

## 测试与验收

- 单元测试覆盖 `LeftFeatureKind` 编解码与幂等迁移、权限状态、AI Provider 选择与降级、FTS 字段边界、File Card 分类、文件冲突、协议解析和邮件最小化存储。
- 集成测试覆盖目录授权与撤销、文件稳定性到确认执行、撤销记录、扩展配对与断连、`gh`/PAT 回退、CLI/API 超时及禁用后的生命周期停止。
- UI 测试覆盖八项功能的启用、排序、紧凑/展开选择、权限空状态、确认界面、键盘操作和错误恢复。
- 能耗测试确认后台无事件时降低采样与轮询频率；禁用所有新增功能时不保留新增监控任务。
- 无障碍验收覆盖 VoiceOver 阅读顺序、44pt 命中区域、颜色之外的状态表达、降低动态效果和大字体布局。
- 最终运行根 Xcode 单元测试、相关 UI 测试、Prototype 测试及 `./scripts/test.sh` 全量回归。

## 明确不在首版范围

- 读取 macOS 历史屏幕使用时间。
- 文档正文索引、向量数据库或云端文件索引。
- 自动执行文件整理、自动修改浏览器书签。
- 直接连接 Gmail、Outlook 等云端邮箱 API。
- 修改邮件状态或创建、编辑、删除日历内容。
- Firefox 浏览器扩展。
