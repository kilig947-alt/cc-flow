# 生产力设置、日历提醒与 GitHub 面板修复设计

## 目标

修复生产力相关设置卡片的信息层级与状态显示，将 File Card 与自然搜索合并为 File Watch，重做日历功能的双栏体验，并让 GitHub 登录检测及数据面板在 `gh` 与 Personal Access Token 两种认证方式下稳定工作。

## 设置页信息层级

「左侧功能」设置页按以下固定顺序显示：

1. Flow 岛显示
2. 功能列表
3. 用 Design 生成功能
4. 生产力连接
5. 权限与数据来源

生产力连接卡片继续提供 GitHub PAT、AI Provider 和浏览器配对设置，但每项都显示明确的保存、连接和错误状态。权限与数据来源卡片从对应服务刷新状态，避免授权完成后仍显示旧结果。

## File Watch

### 功能合并

原「File Card」与「自然搜索」合并为一个内置左侧功能「File Watch」。独立的自然搜索功能不再出现在功能列表或切换栏中。File Watch 在同一展开面板中提供：

- 授权文件夹的添加、移除和刷新。
- File Card 列表、OCR、标签和整理建议。
- 针对 File Card 元数据的自然语言搜索。

搜索入口与文件列表共用同一状态和索引服务，避免用户在两个功能之间切换。搜索结果仅匹配文件名、路径、File Card、OCR 和标签，不搜索文件正文。

### 权限边界

File Watch 的唯一搜索范围是用户在 File Watch 中显式授权的文件夹。索引器和搜索器必须使用同一组安全作用域书签：

- 不扫描或搜索授权目录之外的路径。
- 移除文件夹后，立即停止监听，并从可搜索索引中删除该目录及其后代条目。
- 默认目录只有在用户明确保留或授权后才参与搜索，不因升级或重新启动自动恢复已移除目录。
- 搜索结果返回前再次校验其标准化路径仍位于当前授权目录中，防止陈旧索引越权显示。

### 默认目录与首次授权

File Watch 默认提供 `Downloads` 和 `Documents` 两个目录，但默认展示不等于获得读取权限：

- 首次打开 File Watch 时，若任一默认目录没有有效安全作用域书签，自动打开一次支持多选的系统目录授权窗口。
- 用户可以一次授权两个目录，也可以只授权其中一个。已授权目录进入扫描与搜索范围；未授权目录以“待授权”标签显示，并提供单独授权入口。
- 用户取消授权时不读取目录、不恢复对应缓存搜索结果，也不在当前运行期间反复自动弹出授权窗口。
- 用户主动移除默认目录后记录移除状态，后续启动不自动加回；面板提供“恢复默认目录”操作，恢复后重新进入待授权流程。
- 旧用户已有的有效安全书签保持不变。

点击 File Watch 的“添加文件夹”或默认目录“授权”按钮时，先立即收起 Flow Island，再打开系统目录选择器。选择完成或取消后 Flow Island 保持收起，不自动重新展开。

### 旧数据迁移

升级时移除独立的自然搜索 LeftFeature，并保留 File Card 对应功能，将其显示名更新为 File Watch。若紧凑态或展开态当前选择指向自然搜索，则迁移到 File Watch。原 File Card 的授权目录、安全作用域书签、File Card、OCR 与标签索引继续保留；迁移可重复执行且不会生成重复功能。

## 日历与提醒事项

### 布局

展开态使用双栏布局：

- 左栏是完整月历，包含月份切换、今天快捷操作和选中日期。存在全天事件、普通日程或提醒事项的日期提供可见标记。
- 右栏显示选中日期的节日/日程和 Todo。节日来自 EventKit 中的全天日程，不引入联网节日数据源。
- 默认选中今天；切换月份时保持合法的选中日期，并允许一键回到今天。

紧凑态继续显示最近日程，但优先呈现今天待处理的到期提醒数量。

### Todo 行为

Todo 仅包含已到期和今天到期的未完成 macOS 提醒事项。点击复选框后，通过 EventKit 将对应提醒事项的 `isCompleted` 写为 `true` 并保存，随后立即从列表和待提醒集合移除。关闭主动提醒弹窗不代表完成。

### 主动提醒

新增独立提醒协调器，观察 CalendarService 的待处理 Todo，并接入现有 Flow Island 主动提醒入口：

- 有符合条件的未完成 Todo 时，每 30 分钟最多主动提示一次。
- 一次提示聚合当前全部到期/今日 Todo，避免连续弹出多个窗口。
- 勾选完成后立即重新计算；没有待处理 Todo 时取消后续提示。
- 应用启动、从睡眠恢复、日期跨天和提醒事项刷新时重新计算。
- 记录上次提示时间，避免视图展开、收起或服务刷新造成重复弹窗。

## GitHub 连接与面板

### 认证解析

GitHubService 使用统一认证解析顺序：

1. 检测 `gh` 可执行文件并尝试 `gh auth token`。
2. 若 `gh` 已登录，使用 `gh api` 获取 REST 与 GraphQL 数据。
3. 若 `gh` 不可用、未登录或调用失败，回退到 macOS 钥匙串中的 GitHub PAT。
4. 将未安装 `gh`、`gh` 未登录、PAT 无效、权限范围不足、网络错误和数据解析错误映射为不同状态及恢复建议。

认证失败不会清空最后一次成功数据；UI 将旧数据标记为非最新，同时展示重试或前往设置的入口。

### 展开态布局

展开态恢复终端仪表盘式双栏结构：

- 左栏显示头像、名称、登录名、仓库、关注者和正在关注数量。
- 右栏上方显示贡献热力图及本周统计。热力图按容器可用宽度动态计算列宽、单元格和间距，在面板缩放时完整铺满且不产生横向溢出；窄宽度下优先保留最近周数据。
- 下方显示最近仓库/活动摘要。GraphQL 数据同时读取仓库网页 URL，仓库整行可点击并通过系统默认浏览器打开；鼠标、键盘和 VoiceOver 均可触发，缺失或非法 URL 时保持不可点击并给出说明。
- 加载、空数据、过期数据和认证错误分别呈现，刷新按钮始终可访问。

## AI HOT 内置功能

移除内置「热点新闻/NewsNow」，以新的内置功能「AI HOT」替代：

- 显示名称：`AI HOT`
- 描述：`AI 行业动态聚合`
- 默认地址：`https://aihot.virxact.com/`
- 使用现有远程 WebView、收起后保持运行和 favicon 自动获取能力。

升级迁移在原 NewsNow 功能位置直接转换：保留启用状态、排序、紧凑态/展开态选择、快捷键和自定义面板尺寸，替换功能种类、默认名称、地址及自动 favicon 元数据。迁移可重复执行；若用户已明确自定义图标则保留用户图标。新安装只创建 AI HOT，不再创建 NewsNow。

## 状态与错误处理

- 权限状态由系统授权 API 与实际服务状态共同决定，设置页出现时和用户点击刷新时更新。
- EventKit 保存失败时恢复复选框状态并显示可操作错误，不进行乐观删除。
- GitHub 异步请求避免重复执行，并在主线程统一提交可观察状态。
- 所有图标按钮提供可访问标签，交互目标不小于 44pt；颜色状态同时配有文字或图标。

## 生产力主动通知事件

下载监控、浏览器资源和邮件助手通过统一的 `ProductivityProactiveEventCenter` 发布主动通知事件，由 Flow Island 统一消费并展开对应左侧功能，不伪造 Hook Session。

### 触发规则

- 下载监控：同一浏览器与下载 ID 首次出现时发布“新下载开始”；状态首次进入 `complete` 时再发布一次“下载完成”。中间进度、重复状态和完成后的重复消息不触发。
- 浏览器资源：浏览器扩展成功保存新的 URL 时发布事件；已存在 URL 的标题或时间更新不重复触发。用户在面板中手动录入 URL 不触发主动弹出。
- 邮件助手：首次成功读取只建立邮件 ID 基线，不弹出；后续轮询仅对新增邮件 ID 发布事件。一次轮询发现多封新邮件时合并为一个事件。

### 展开与去重

- 事件携带目标 LeftFeature ID、事件类型、摘要和服务级单调序号。
- 同一目标在 5 秒聚合窗口内的多个事件合并为一次弹出，展示最新摘要和累计数量。
- Flow Island 消费事件时把 `expandedActiveFeatureID` 切换为目标功能，并以 `.notification` 原因调用现有自定义功能展开入口。
- 事件序号在事件中心内一次性消费；窗口或 SwiftUI View 重建不会重复弹出旧事件。
- 对应功能禁用、全局/临时通知静音、用户正在进行文本输入、权限确认或人工干预时，不强制展开。被抑制的即时事件不延迟补弹，避免恢复交互后出现过期通知。

## 测试

新增或更新测试覆盖：

- 设置页五个区块的固定顺序。
- File Watch 功能种类与旧 File Card/自然搜索选择迁移。
- 搜索只能返回当前授权目录中的 File Card 元数据，移除授权后旧索引不再可见。
- Downloads/Documents 默认占位、首次联合授权、部分授权与取消授权。
- 默认目录移除后不自动恢复，以及手动恢复后的待授权状态。
- 无有效书签的默认/保存目录不能扫描或返回缓存结果。
- 点击添加/授权目录时先收起 Flow Island，选择器结束后保持收起。
- 月份日期网格、选中日期和日程映射。
- 已到期/今天到期提醒筛选，未来和无日期提醒排除。
- 30 分钟提醒节流、跨天重算和完成后停止提醒。
- EventKit 提醒完成写回的成功及失败路径。
- GitHub `gh`、PAT 回退顺序和错误分类。
- GitHub 数据解析及保留最后一次成功快照。
- GitHub 热力图在多种容器宽度下无溢出，并优先展示最近贡献周。
- GitHub 仓库 URL 解析、合法性校验和浏览器跳转动作。
- NewsNow 到 AI HOT 的原位迁移与新安装默认功能创建。
- 下载开始、下载完成的状态跃迁去重，同一下载的进度消息不触发。
- 浏览器资源仅对扩展新增 URL 触发，重复 URL 和手动保存不触发。
- 邮件首次读取建立基线，后续新增 ID 聚合触发。
- 主动事件 5 秒聚合、一次性消费、功能禁用及通知抑制行为。

## 范围限制

- 不接入第三方节假日 API。
- 不为未来或无日期提醒事项发送每 30 分钟主动提示。
- 除将原自然搜索选择迁移到 File Watch 外，不改变其他左侧功能的排序、紧凑态选择或自定义功能数据格式。
