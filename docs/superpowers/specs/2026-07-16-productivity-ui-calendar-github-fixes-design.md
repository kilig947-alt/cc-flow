# 生产力设置、日历提醒与 GitHub 面板修复设计

## 目标

修复生产力相关设置卡片的信息层级与状态显示，重做日历功能的双栏体验，并让 GitHub 登录检测及数据面板在 `gh` 与 Personal Access Token 两种认证方式下稳定工作。

## 设置页信息层级

「左侧功能」设置页按以下固定顺序显示：

1. Flow 岛显示
2. 功能列表
3. 用 Design 生成功能
4. 生产力连接
5. 权限与数据来源

生产力连接卡片继续提供 GitHub PAT、AI Provider 和浏览器配对设置，但每项都显示明确的保存、连接和错误状态。权限与数据来源卡片从对应服务刷新状态，避免授权完成后仍显示旧结果。

## 日历与提醒事项

### 布局

展开态使用双栏布局：

- 左栏是完整月历，包含月份切换、今天快捷操作和选中日期。存在全天事件、普通日程或提醒事项的日期提供可见标记。
- 右栏显示选中日期的节日/日程和 Todo。节日来自 EventKit 中的全天日程，不引入联网节日数据源。
- 默认选中今天；切换月份时保持合法的选中日期，并允许一键回到今天。

紧凑态继续显示最近日程，但优先呈现今天待处理的到期提醒数量。

### Todo 行为

Todo 仅包含已到期和今天到期的未完成 macOS 提醒事项。点击复选框后，通过 EventKit 将对应提醒事项的 `isCompleted` 写为 `true` 并保存，随后立即从列表和待提醒集合移除。关闭主动提醒弹窗不代表完成。

### 主动提醒

新增独立提醒协调器，观察 CalendarService 的待处理 Todo，并接入现有 Flow Island 主动提醒入口：

- 有符合条件的未完成 Todo 时，每 30 分钟最多主动提示一次。
- 一次提示聚合当前全部到期/今日 Todo，避免连续弹出多个窗口。
- 勾选完成后立即重新计算；没有待处理 Todo 时取消后续提示。
- 应用启动、从睡眠恢复、日期跨天和提醒事项刷新时重新计算。
- 记录上次提示时间，避免视图展开、收起或服务刷新造成重复弹窗。

## GitHub 连接与面板

### 认证解析

GitHubService 使用统一认证解析顺序：

1. 检测 `gh` 可执行文件并尝试 `gh auth token`。
2. 若 `gh` 已登录，使用 `gh api` 获取 REST 与 GraphQL 数据。
3. 若 `gh` 不可用、未登录或调用失败，回退到 macOS 钥匙串中的 GitHub PAT。
4. 将未安装 `gh`、`gh` 未登录、PAT 无效、权限范围不足、网络错误和数据解析错误映射为不同状态及恢复建议。

认证失败不会清空最后一次成功数据；UI 将旧数据标记为非最新，同时展示重试或前往设置的入口。

### 展开态布局

展开态恢复终端仪表盘式双栏结构：

- 左栏显示头像、名称、登录名、仓库、关注者和正在关注数量。
- 右栏上方显示固定宽度的贡献热力图及本周统计，下方显示最近仓库/活动摘要。
- 加载、空数据、过期数据和认证错误分别呈现，刷新按钮始终可访问。

## 状态与错误处理

- 权限状态由系统授权 API 与实际服务状态共同决定，设置页出现时和用户点击刷新时更新。
- EventKit 保存失败时恢复复选框状态并显示可操作错误，不进行乐观删除。
- GitHub 异步请求避免重复执行，并在主线程统一提交可观察状态。
- 所有图标按钮提供可访问标签，交互目标不小于 44pt；颜色状态同时配有文字或图标。

## 测试

新增或更新测试覆盖：

- 设置页五个区块的固定顺序。
- 月份日期网格、选中日期和日程映射。
- 已到期/今天到期提醒筛选，未来和无日期提醒排除。
- 30 分钟提醒节流、跨天重算和完成后停止提醒。
- EventKit 提醒完成写回的成功及失败路径。
- GitHub `gh`、PAT 回退顺序和错误分类。
- GitHub 数据解析及保留最后一次成功快照。

## 范围限制

- 不接入第三方节假日 API。
- 不为未来或无日期提醒事项发送每 30 分钟主动提示。
- 不改变其他左侧功能的排序、紧凑态选择或自定义功能数据格式。
